🗄️ Relational Database Management System (PostgreSQL) Architecture

This system satisfies 3NF (Third Normal Form) relational design principles for academic evaluation.

1. departments Table

Primary Key: department_id

Stores 10 specialized hospital departments.
2. doctors Table

PK: doctor_id | FK: department_id

10 certified doctors linked by Foreign Key to department.
3. patients Table

PK: patient_id (or phone/email unique)

Stores enrolled patient profiles with password credentials.
4. appointments Table

PK: appointment_id | UK: appointment_ref

Central transaction table. Reason is optional; Status tracked.
5. appointment_change_requests

PK: request_id | FK: appointment_ref

Stores Reschedule and Cancellation requests.
6. Notifications (Admin & Patient)

Real-time messaging

Synchronizes decisions between admin and patient.
-- Sample SQL Query: Active Appointments with Doctor & Department Joins
SELECT a.appointment_ref, a.patient_name, d.name AS department, doc.name AS doctor, a.appointment_date, a.appointment_time, a.status
FROM appointments a
JOIN departments d ON a.department_id = d.department_id
JOIN doctors doc ON a.doctor_id = doc.doctor_id
ORDER BY a.created_at DESC;
